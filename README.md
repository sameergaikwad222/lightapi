# LightAPI

A lightweight, fast and modern REST API client built with React.

## Screenshot

LightAPI request workspace with query parameters and response viewer.

![LightAPI workspace showing the request editor, query parameters, and response viewer](docs/screenshots/lightapi-workspace.png)

## Features

- REST API Testing
- Query Parameters
- Headers
- JSON Body
- Bearer / Basic / API Key Authentication
- Request History
- Collections
- Local Storage
- Import / Export
- Environment Variables
- GraphQL (Coming Soon)
- WebSocket (Coming Soon)
